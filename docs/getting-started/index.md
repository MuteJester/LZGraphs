## Prerequisites

- **Python 3.9+** and **NumPy** (installed automatically)
- Basic Python knowledge (lists, dicts, loops)
- Some familiarity with CDR3 / TCR / BCR sequences is helpful but not required;
  the tutorials explain the biology as needed
